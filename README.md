# Daily Coding Drills

Blank-file practice repo. The goal is to rebuild small frontend and backend pieces from memory — not to copy from AI or tutorials while drilling.

## How it works

Each day:

1. Create a dated subfolder for the drill, e.g.:
   - `frontend/day-01-xxx/`
   - `backend/day-01-xxx/`
2. Write the code yourself, from memory.
3. Keep Cursor Tab / AI autocomplete **off** for this project (see `.vscode/settings.json`).
4. Log the session in `LOG.md` — especially anything you couldn't recall.

The Vite app in `frontend/` and FastAPI app in `backend/` are scaffolds only. Do not treat them as the drill solutions. Practice code lives in the daily folders.

## Run the scaffolds

See [`runable`](./runable) for the exact commands to start each app.

Backend defaults to port **8001** so it does not clash with other local services on 8000.
